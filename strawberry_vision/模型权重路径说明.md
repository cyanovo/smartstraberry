# 三号模型权重路径说明

本工程是学生新的训练起点，不再要求学生提供不存在的旧训练入口、测试脚本或依赖说明。现有脚本依据原 PPT 的代码截图补齐。

以下路径均相对 `strawberry_vision` 工程目录。**这是存放约定，不是文件已经存在的证明。当前尚未下载初始权重，也尚未生成草莓训练权重。**

## 一、初始权重

| 用途 | 约定路径 | 来源与状态 |
|---|---|---|
| YOLO26n 候选主线 | `weights/yolo26n.pt` | 从 Ultralytics 官方来源取得，目前待准备 |
| YOLO11n 对照 | `weights/yolo11n.pt` | 从 Ultralytics 官方来源取得，目前待准备 |

官方入口：[YOLO26](https://docs.ultralytics.com/models/yolo26/)、[YOLO11](https://docs.ultralytics.com/models/yolo11/)。下载时记录实际地址、发行版本、时间和文件 SHA256。只使用可信权重，不将来源不明的 PT 文件交给 PyTorch 加载。

这些通用预训练权重不是已训练好的草莓成熟度模型，不能直接把它们的检测结果当作本项目效果。

## 二、训练产生的权重

以 `--name y26_baseline01` 为例，预计输出如下，最终以终端打印的 `Best weights` 为准：

| 文件 | 用途 |
|---|---|
| `runs/y26_baseline01/train/weights/best.pt` | 依据验证表现选出的模型，供独立测试与单图演示 |
| `runs/y26_baseline01/train/weights/last.pt` | 训练最后保存的检查点；是否生成以实际运行结果为准 |
| `runs/y26_baseline01/train/args.yaml` | 实际训练参数 |
| `runs/y26_baseline01/dataset.resolved.yaml` | 本轮数据配置的绝对路径副本 |

初始权重不能改名为 `best.pt` 冒充训练成果。原截图中的 `weights/bch.pt` 用途未确认，本工程不沿用这个含义不明的名字。

## 三、评估报告路径

| 运行 | 预计结果文件 | 含义 |
|---|---|---|
| 训练后验证 | `runs/y26_baseline01/validation/metrics.json` | 验证集结果，不是最终测试集成绩 |
| `test.py --name y26_test01` | `runs/y26_test01/test/metrics.json` | 独立测试集结果 |
| `predict.py --name y26_predict01` | `runs/y26_predict01/predict/` | 单图检测画面与标签，不提供总体准确率 |

图表是否生成、具体文件名以实际框架输出为准。`metrics.json` 已由脚本自动保存，但只能在评估成功后出现。

## 四、核对与登记

在工程目录中检查模型是否存在，并记录校验值：

```powershell
Test-Path -LiteralPath '.\weights\yolo26n.pt'
Get-FileHash -LiteralPath '.\weights\yolo26n.pt' -Algorithm SHA256
```

训练完成后，对真实 `best.pt` 同样计算 SHA256，将结果登记到评估报告中。模型交给其他电脑后重新计算核对，类别表和预处理要求必须一并交付。

## 五、当前还缺什么

需要实际准备的是官方初始权重、与二号一致的检测类别表、已标注图片及数据划分。草莓权重与实测报告由后续训练、评估产生，不要求学生提前交一份不存在的成果。
