# 草莓项目学生部署包

版本：student-2026.10.26。包含新版病害问答、设备建议、文件夹导入和全部原图ZIP下载。

**已部署旧版的学生不要覆盖解压。** 使用配套增量包，让AI阅读UPDATE.md并保留自己的数据库、图片、模型及代码。下面仅是首次部署流程。

1. 将整个压缩包解压到较短的英文目录，例如 `D:\StrawberryStudent`，不要在压缩包里运行。
2. 用你使用的本地 AI 编程工具打开解压目录，发送下面这句话：

> 请阅读 AGENTS.md 和 AGENT_DEPLOY.md，直接在本机完成这个草莓项目的 Windows 原生部署，运行测试，修复发现的问题并重新测试。不要用 Docker 或 WSL，不要只告诉我命令。保留业务数据，最后提供访问地址、登录方式、测试截图和 DEPLOY_RESULT.md。知识库和 Ollama 由我们以后自己创建安装。

3. 也可以先双击 `deploy.cmd`；若失败，把完整报错交给 AI。
4. 部署成功后登录信息在 `LOGIN.txt`；网页地址以 web 窗口显示为准，默认 http://127.0.0.1:5179 。
5. 后续先双击 `Newsmart-Strawberry/start-services.cmd`，再运行 `start-api.cmd`、`start-web.cmd`。每个服务在自己的窗口运行，关闭对应窗口即可停止该服务。

包内含教学数据和模型服务配置，只在授权班级内分享，不要公开上传。建议准备 50 GB 可用磁盘、16 GB 内存。没有显卡可以先用 CPU 训练，但会慢。IDE、Git、Ollama 不包含在包中。
