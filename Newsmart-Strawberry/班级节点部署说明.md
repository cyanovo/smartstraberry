# 班级节点部署说明

后续可以指定一个学生电脑作为班级节点。这个学生负责同时运行：

- Git 仓库服务：提供源码同步
- Docker 镜像仓库：提供依赖镜像拉取

其他学生只从这个班级节点拉源码和镜像，不直接访问 GitHub、npm、PyPI 或 Docker Hub。

## 班级节点电脑

老师电脑运行：

```text
..\package-classroom-node.cmd
```

会生成：

```text
classroom-node-package
```

把这个目录压缩后发给班级节点学生。班级节点学生解压后，双击：

```text
classroom-node-launcher/start-classroom-node.cmd
```

启动器会自动启动 Git 仓库和 Docker 镜像仓库，并显示给其他学生使用的地址。

停止服务双击：

```text
classroom-node-launcher/stop-classroom-node.cmd
```

查看状态双击：

```text
classroom-node-launcher/status-classroom-node.cmd
```

## 其他学生电脑

第一次从班级节点拉源码：

```powershell
git clone http://班级节点IP:3080/admin/tomatosmart.git
```

进入项目目录后，双击：

```text
student-sync-start.cmd
```

第一次运行时输入班级节点 IP，脚本会保存到本机的 `classroom-settings.local.ps1`。以后直接双击即可。

## Docker Desktop 设置

其他学生需要允许访问班级节点的 HTTP 镜像仓库。

Docker Desktop -> Settings -> Docker Engine，加入：

```json
{
  "insecure-registries": ["班级节点IP:5000"]
}
```

然后重启 Docker Desktop。

## 日常更新

老师或班级节点维护者把代码推到本地 Git 仓库后，其他学生只需要再次双击：

```text
student-sync-start.cmd
```

脚本会自动：

1. 从班级节点 Git 仓库同步源码
2. 从班级节点镜像仓库拉取镜像
3. 使用 `--no-build` 启动，避免重新下载依赖
