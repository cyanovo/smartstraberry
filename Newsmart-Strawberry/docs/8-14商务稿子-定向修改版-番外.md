**项目经理：** 番茄是我们日常生活中最常见的蔬菜之一，但它其实是一种**非常"娇贵"的作物**。

**第一，番茄对生长环境要求高。** 温度、湿度、光照、土壤养分，任何一个参数偏离最佳范围，都可能引发病害或影响品质。

**第二，番茄容易生病虫害。** 早疫病、晚疫病、灰霉病、蚜虫……据统计，番茄生长周期内可能遭遇的病虫害超过20种，而且**很多病害在早期肉眼难以察觉**，等到症状明显时往往已经大面积蔓延。

**第三，番茄成熟后不易储存运输。** 番茄果皮薄、含水量高，采摘后常温下2-3天就会变软腐烂。**采摘时机非常关键**——早了口感差、晚了不耐运。

**第四，番茄种植全程需要预防。** 与其等到病害发生再治，不如提前监测、提前干预。但传统种植中，**"预防"高度依赖经验**，年轻一代农户往往缺乏这种经验。（翻页）

**项目经理：** 正是因为番茄"娇贵、易病、怕晚、重防"这四个特点，使得它成为了**智慧农业技术落地的典型场景**。接下来，我请团队成员分别介绍我们发现的四大核心痛点及对应的解决方案。

```python
async def sensor_data_send(uart, s):
    if not wifi_connected or not mqtt_connected:
        return
    # 发送modbus查询指令
    uart.write(bytes.fromhex(s))
    await asyncio.sleep_ms(500)
    raw_data = uart.read()
    if raw_data is None or len(raw_data) < 2:
        return
    addr = raw_data.hex()[:2]
    # 空气传感器 地址01
    if addr == "01":
        r = raw_data[3:-2]
        humidity = ustruct.unpack(">H", r[0:2])[0] / 10.0
        temp = ustruct.unpack(">H", r[2:4])[0] / 10.0
        co2 = ustruct.unpack(">H", r[4:6])[0]
        illum = ustruct.unpack(">H", r[6:8])[0]
        global _t0, _t1, _t2
        _t0, _t1, _t2 = temp, co2, illum
        client.publish("/air/post", ujson.dumps({
            "humidity": humidity, "temp": temp,
            "co2": co2, "Illumination": illum
        }))
    # 土壤传感器 地址02
    elif addr == "02":
        r = raw_data[3:-2]
        sm = ustruct.unpack(">H", r[0:2])[0] / 10.0
        st = ustruct.unpack(">H", r[2:4])[0] / 10.0
        n  = ustruct.unpack(">H", r[8:10])[0]
        p  = ustruct.unpack(">H", r[10:12])[0]
        k  = ustruct.unpack(">H", r[12:14])[0]
        global _t3, _t4, _t5, _t6, _t7
        _t3, _t4, _t5, _t6, _t7 = st, sm, n, p, k
        client.publish("/soil/post", ujson.dumps({
            "soil_moisture": sm, "soil_temperature": st,
            "nitrogen": n, "phosphorus": p, "potassium": k
        }))
```

**嵌入式工程师：** 这段代码主要完成三个任务：第一，通过UART向RS485传感器发送Modbus读取请求；第二，根据设备地址分别解析空气和土壤传感器返回的二进制数据，并将放大后的整数还原为实际数值；第三，将数据发布到MQTT主题。程序还加入了**网络连接判断、数据长度校验和异常捕获**，避免无效数据进入系统。

**AI应用开发工程师：** 下面进入核心代码实现。本次聚焦知识库检索函数：先读取知识库配置与参数；再通过检索器执行检索，若目标知识库不存在时返回友好提示，避免程序崩溃；为增强健壮性，先查询可见知识库列表，再根据ID精确查找，避免因权限或配置问题导致检索失败；执行检索后，统一输出结构，将检索结果转为列表；最后为每条结果添加编号，方便后续引用与核验。

```python
@tool(category="knowledge", tags=["知识库"], args_schema=QueryKBInput)
async def query_kb(
    kb_id: str,
    query_text: str,
    file_name: str | None = None,
    runtime: ToolRuntime = None
) -> Any:
    """在指定知识库中检索内容"""
    if not kb_id:
        return "请提供 kb_id"
    if not query_text:
        return "请提供查询内容"

    # 获取系统中已注册的知识库检索器
    retrievers = knowledge_base.get_retrievers()
    # 查询当前用户有权访问的知识库列表
    visible_kbs = await _resolve_visible_knowledge_bases_for_query(runtime)

    # 根据知识库ID查找目标知识库并进行权限校验
    target_info, target_kb_id, target_error = _find_query_target(
        kb_id=kb_id,
        retrievers=retrievers,
        visible_kbs=visible_kbs
    )

    if target_error:
        return target_error

    try:
        retriever = target_info["retriever"]
        kwargs = {}
        if file_name:
            kwargs["file_name"] = file_name

        if inspect.iscoroutinefunction(retriever):
            result = await retriever(query_text, **kwargs)
        else:
            result = retriever(query_text, **kwargs)

        # 统一输出结构
        if isinstance(result, dict) and result.get("kb_id") == target_kb_id:
            output = SearchOutputSchema(**result)
        else:
            output = KnowledgeBase.build_search_output(target_kb_id, result)

        # 为每条结果添加来源编号
        output_data = output.model_dump() if isinstance(output, SearchOutputSchema) else {"kb_id": target_kb_id, "results": []}

        for i, item in enumerate(output_data.get("results") or []):
            source_name = (item.get("metadata") or {}).get("source", "")
            item["content"] = f"【来源 {i + 1}】{source_name}\n{item['content']}"

        return output_data
    except Exception as e:
        return f"检索异常：{str(e)}"
```
